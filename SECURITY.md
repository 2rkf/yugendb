# Security Policy

## Supported versions

Security fixes target the current `0.1` release line.

## Reporting a vulnerability

Please report security issues privately to the maintainers before opening a public issue.

Include as much detail as you can safely share:

- affected package or crate;
- backend driver involved, if any;
- steps to reproduce;
- expected and actual behaviour;
- potential impact.

Maintainers will review the report, prepare a fix where needed, and publish release notes with appropriate detail.
